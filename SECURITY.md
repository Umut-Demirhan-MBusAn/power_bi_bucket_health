# Security Policy

## Supported versions

Only the latest [release](https://github.com/Umut-Demirhan-MBusAn/power_bi_bucket_health/releases)
receives fixes.

## Reporting a vulnerability

Report privately through GitHub:
[**Report a vulnerability**](https://github.com/Umut-Demirhan-MBusAn/power_bi_bucket_health/security/advisories/new)
(Security tab → Report a vulnerability). Do not open a public issue.

Include the affected version, steps to reproduce, and the impact. Maintainer: Umut Demirhan.
