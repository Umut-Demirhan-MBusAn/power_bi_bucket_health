Privacy Policy

Bucket Health for Power BI  ·  Last updated: June 2026

No personal data collected or transmitted

Overview

Bucket Health is a Microsoft Power BI custom visual that renders a real-time schematic of mining excavator bucket GET (Ground Engaging Tools) component health status. The visual operates entirely within the Power BI report client and does not transmit any data to external servers.

Data Access

The visual receives data exclusively from the Power BI host environment via the standard DataView API. It reads the following field types that you bind in the Fields pane:

  • Machine identifier and type label
  • Component key, category, and order
  • Component health status strings
  • Optional: last-seen timestamp, alarm time, and user-defined tooltip fields

No credentials, usernames, passwords, or other personal identifiers are required or accessed.

Data Processing & Storage

All data processing occurs in-memory, client-side, within the Power BI rendering engine on the end user's device:

  • No data is sent to any external server, API, or third-party service.
  • No data is written to local storage, IndexedDB, cookies, or any persistent browser store.
  • No user activity, interaction patterns, telemetry, or analytics are collected.
  • No data leaves the Power BI report context at any point.

The visual uses the WebAudio API solely to generate a two-tone alert tone from mathematical oscillators. No audio is recorded and no microphone access is requested.

Network Access

The visual makes no network requests of any kind. The WebAccess privilege is not declared in the visual's capabilities manifest, which prevents any outbound HTTP, WebSocket, or similar connection from being established.

Third-Party Services

No third-party SDKs, analytics libraries, tracking pixels, or external fonts are loaded. All rendering is performed with browser-native SVG and DOM APIs only.

Children's Privacy

This visual is an industrial monitoring tool intended for use by operations personnel in mining and heavy-equipment industries. It is not directed at children and does not knowingly process data relating to children.

Changes to This Policy

If the privacy practices change in a future version (for example, if optional telemetry is added), this page will be updated and the "Last updated" date will change. Continued use of the visual after such changes constitutes acceptance of the updated policy.
