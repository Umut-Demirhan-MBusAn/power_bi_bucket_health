Edge State Guide

The visual shows one of five informational states when it cannot render machines:

State shownCauseFix
Add data to get started No fields are bound to the visual. Drag the required fields from the Fields pane: Machine, Component, Category, Order, Status.
Configuration incomplete One or more required roles are missing. Check that every role listed below the message is bound in the Fields pane.
No machines to show Data is bound but current slicers/filters return zero rows. Clear or adjust the report page filters.
Loading machine data Power BI is still fetching data. Wait; this resolves automatically when data is ready.
Couldn't render the visual An unexpected parsing or rendering error occurred. Check the error detail message shown in the visual. Common causes: unsupported status strings, missing lip shroud rows for a tooth count. See the data schema docs.

Required Data Schema

Each row must represent one component on one machine. The following columns are required:

Field roleDescriptionExample
MachineUnique identifier for each excavatorEX-204
ComponentComponent key (unique per machine)T5, L2, W3R
CategoryComponent typetooth, lipShroud, wingShroud
OrderInteger position (left-to-right for teeth/lips; side-assignment for wings)1, 2, …
StatusHealth status stringOK, No Data, Proximity Alarm, Movement Alarm, Lockout

Optional roles: Machine Type, Last Seen, Alarm Time, Tooltip Fields (multi-column).

Full schema: docs/DATA_SCHEMA.md

Formatting Pane Settings

SettingDescription
Layout → Minimum card widthCards will not shrink below this pixel width; a scrollbar appears instead. Default: 220 px.
Ordering → Wing side assignmentControls how wing shroud order values map to left/right sides. Choose a mode that matches your data convention.
Ordering → Teeth & lip orderRender teeth/lip shrouds left-to-right or right-to-left.
Alarm → Enable audio alarmEnable/disable the two-tone beep when a component transitions into alarm status.
Alarm → Alarm motionAlways flash: ignores OS reduced-motion. Auto: respects the OS setting. Never: solid (non-flashing) alarm.
